# Desk Companion

A personalized Raspberry Pi desk display built with Python and Tkinter.

## Version 0.2

Version 0.2 includes:

- A full-screen digital clock
- Time that updates every second
- Automatic launch after desktop sign-in
- A custom visual theme
- Personalized time-of-day greetings
- Touch controls for showing or hiding seconds
- A cleaner top, center, and bottom layout
- An Escape key to close the application

Built one mission at a time.
